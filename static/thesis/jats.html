The interactive JATS reader

This page parses downloads/thesis_jats.xml live in your browser with the DOM parser, the same way a publisher's production system ingests it. Sections, the abstract, keywords, and the 77-entry reference list are rendered structurally, not as plain text. The file itself is the NLM JATS 1.3 Journal Publishing XML required by PubMed Central, Springer, Elsevier, and PLOS submission systems.
